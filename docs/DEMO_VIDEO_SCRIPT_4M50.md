## 0:00–0:22 — Hook / problem

**Visual**
- clean title card: `Agent Recovery Platform`
- subtitle: `Verified recovery for compromised autonomous AI agents`
- animate lifecycle strip faintly in background

**Voiceover**
AI agents are starting to change real state: customer records, shared memory, access controls and workflows. A kill switch can stop the next action. It cannot tell you what already changed, what propagated to other agents, what can be reversed, or when it is safe to restore authority.

## 0:22–0:42 — Product thesis

**Visual**
- show the six-stage strip:
  `incident -> containment -> evidence -> recovery -> replay -> verified restoration`
- split-screen trust boundary: `Strands reasoning` vs `Deterministic control plane`

**Voiceover**
Agent Recovery Platform starts after prevention fails. Strands agents investigate evidence, propose recovery and challenge assumptions. But model output never authorizes execution. Deterministic controls own containment, recovery, replay and restoration.

## 0:42–1:32 — Working incident

**Visual**
- Judge Incident Recovery Console
- highlight Support Agent
- animate propagation Support -> Workflow -> Identity
- show `3 / 3 blast actions detected`

**Voiceover**
Here is one bounded deterministic incident. Poisoned external content reaches a support agent, which writes compromised shared state. That state influences downstream workflow and identity authority. The platform reconstructs the represented causal blast radius instead of trusting the compromised agent's narration.

In this fixture, all three expected blast actions are represented and detected. The compromised root is contained, and dependent authority is held while recovery runs.

## 1:32–2:15 — Agentic reasoning, no authority

**Visual**
- three horizontal cards: Investigator, Recovery Planner, Skeptic
- each card has a small badge: `READ-ONLY / PROPOSAL ONLY`
- show evidence IDs flowing into cards, not tool execution arrows

**Voiceover**
The Investigator forms an evidence-cited root-cause hypothesis. The Recovery Planner proposes ordered candidate actions and residual risks. The Skeptic challenges unsupported assumptions and unsafe recovery claims.

The important boundary is what they cannot do: these agents cannot approve a write, execute recovery or restore authority. Their output must be rebound to current incident evidence before deterministic code can act on anything.

## 2:15–3:14 — Deterministic recovery

**Visual**
- zoom into deterministic control plane
- cards: Recovery Contract, Ledger, Causal Graph, Recovery Engine
- show three recoveries turning green
- show explicit residual-risk panel, even if current selected fixture has zero platform residual effects

**Voiceover**
Every consequential action is governed by a Recovery Contract describing its side effects, recovery class, verifier and approval requirements. The action ledger preserves represented evidence independently from model narration.

Recovery is incident-bound, approvals are single-use within the trusted runtime, malformed recovery contracts fail closed, and later writers of shared state prevent unsafe rollback. Irreversible or failed compensation is never relabeled as recovered. It remains visible as residual risk.

In this selected fixture, three represented recoveries verify successfully and there are zero unsafe recovery executions.

## 3:14–4:02 — Replay and selective restoration

**Visual**
- Replay Lab panel
- show exact represented attack action entering isolated replay
- display green `Replay verified`
- then show Workflow and Identity change from Contained -> Restored
- Support Agent stays red `Contained`

**Voiceover**
Recovery is not enough to restore authority. The platform runs a bounded replay of the represented attack action against the repaired state. Replay evidence is bound to the incident, source action, state generation, contract versions and proposed release scope. Stale, cross-incident, superseded or environment-mismatched evidence fails closed.

Only after recovery obligations and replay evidence agree can downstream authority be restored. Here, two downstream authorities return. The compromised root remains contained.

It found lifecycle counterexamples ordinary tests missed, including false restoration authorization, replay-context confusion, containment reconstruction and approval reuse. We treated those findings as blockers and converted them into permanent regression coverage.

The final submission uses exact-head CI, deterministic benchmark evidence and a credential-free reproduction path.
